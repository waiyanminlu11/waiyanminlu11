I'm a final-year Information Science & Technology student who builds **AI systems that operate in the physical world** — from computer-vision models running on edge hardware, to IoT sensor networks feeding real-time dashboards. I'm most interested in the space where **machine learning meets embedded systems**: making models small, fast, and reliable enough to run on a Raspberry Pi or ESP32 in the field, not just in a notebook.

### 🚀 Featured Projects

#### Smart AI City Platform
An end-to-end smart-city prototype combining live traffic-camera analytics, fire/smoke detection, adaptive traffic-light control, and environmental (air/flood) monitoring behind one FastAPI backend, with a React operator dashboard.

| Repository | Description | Stack |
|---|---|---|
| 🖥️ [`smart-ai-city-api`](https://github.com/waiyanminlu11/smart-ai-city-api) | Modular FastAPI backend: YOLO traffic & fire/smoke detection, ESP32 traffic-light control, air/flood telemetry, optional AI assistant | FastAPI, Ultralytics YOLO, OpenCV, TensorFlow/Keras, SQLAlchemy |
| 📊 [`smart-ai-city-dashboard`](https://github.com/waiyanminlu11/smart-ai-city-dashboard) | Operator-facing control-room UI — live camera feeds, traffic/fire status, environmental panels, historical charts | React 19, TypeScript, Vite, Tailwind CSS, Radix UI |

#### Air Pollution & Flood Early Warning System
A standalone Smart City subsystem that ingests Raspberry Pi sensor telemetry roughly every 5 seconds, tracks air quality and water levels, and predicts flood risk with a GRU model.

| Repository | Description | Stack |
|---|---|---|
| 🌊 [`air-flood-monitoring-api`](https://github.com/waiyanminlu11/air-flood-monitoring-api) | FastAPI backend for sensor ingestion, flood decision logic, GRU-based water-level prediction, and OpenWeather-enriched air-quality data | FastAPI, SQLAlchemy, TensorFlow/Keras (GRU), APScheduler |
| 📈 [`air-flood-monitoring-dashboard`](https://github.com/waiyanminlu11/air-flood-monitoring-dashboard) | Live monitoring dashboard for telemetry, flood status/predictions, and historical trends | React 19, Vite, Chart.js |
